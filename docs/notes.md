# Technical Notes - TaskTrack-API

## 1. أكبر مشكلة واجهتني في دوكر وكيف حليتها
* **المشكلة:** توقف محرك Docker Desktop بسبب خطأ تحديث نظام WSL 2 المتعلق بتعارض خدمات الويندوز (`0x8024001e`).
* **الحل:** قمت بتحميل ملف التحديث اليدوي لـ WSL بصيغة `.msi` (`wsl.3.0.5.0.x64.msi`) وثبته يدوياً، مما أدى لعمل المحرك بنجاح.

## 2. أهم درس تعلمته من Git و GitHub
* **الدرس المستفاد:** تنظيم الملفات وتقسيمها (مثل `src/` و `docs/`) واستخدام رسائل Commit واضحة يجعل المشروع احترافياً وسهل التشغيل والصيانة لأي مطور آخر.

## ملاحظات النشر على الـ VPS

أثناء رفع المشروع على سيرفر  VPS واجهتني شغلتين وحليتهم كالتالي

أول شي لما حاولت أدخل على السيرفر من جهاز اللابتوب عن طريق SSH على بورت 22 كان الاتصال يقفل فدخلت مباشرة من متصفح الويب عن طريق Hostinger Web Terminal واشتغل معي عادي

ثاني شي نظام Ubuntu كان فيه Git جاهز بس Docker ما كان نازل ولما لصقت أمر التثبيت في تيرمنال الويب طلعت رموز لصق زيادة وعملت خطأ فكتبت أمر تثبيت docker.io بشكل نظيف وشغلت خدمة docker وبعدين بنيت الصورة وشغلت الحاوية على بورت 3000 واشتغل ال API بدون مشاكل
