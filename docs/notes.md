# Technical Notes - TaskTrack-API

## 1. أكبر مشكلة واجهتني في دوكر وكيف حليتها
* **المشكلة:** توقف محرك Docker Desktop بسبب خطأ تحديث نظام WSL 2 المتعلق بتعارض خدمات الويندوز (`0x8024001e`).
* **الحل:** قمت بتحميل ملف التحديث اليدوي لـ WSL بصيغة `.msi` (`wsl.3.0.5.0.x64.msi`) وثبته يدوياً، مما أدى لعمل المحرك بنجاح.

## 2. أهم درس تعلمته من Git و GitHub
* **الدرس المستفاد:** تنظيم الملفات وتقسيمها (مثل `src/` و `docs/`) واستخدام رسائل Commit واضحة يجعل المشروع احترافياً وسهل التشغيل والصيانة لأي مطور آخر.
